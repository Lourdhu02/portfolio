## The Incident

During a staged deployment of the SVTRv2 sequence recognition model, canary telemetry flagged an anomalous drop in end-to-end exact match accuracy from **84.0% down to 64.2%** on a batch of 2,950 meter images. 

Field verification showed that numeric readings with repeated consecutive digits were severely truncated. For example, a meter displaying `4777.1 kWh` was consistently decoded as `47.1 kWh`.

## Root Cause Analysis

The sequence recognizer outputs CTC (Connectionist Temporal Classification) frame logits. Under CTC decoding rules:
1. Identical consecutive tokens emitted across contiguous time steps must be collapsed into a single token.
2. A special **blank token** (`ε`) separates distinct consecutive occurrences of the same character.

In our vectorized C++ post-processing kernel, an optimization had inadvertently cached the previous emission index without resetting upon encountering the blank token:

```python
# The regression:
if token != blank_id and token != prev_token:
    decoded.append(token)
prev_token = token  # Blank tokens did not clear prev_token!
```

When the sequence `[4, ε, 7, ε, 7, ε, 7, 1]` passed through, the second and third `7` were ignored because `prev_token` remained `7` despite intervening blanks!

## The Fix

The fix was straightforward but critical:

```python
# The fix:
if token != blank_id:
    if token != prev_token:
        decoded.append(token)
    prev_token = token
else:
    prev_token = None  # Reset state on blank frame
```

## Production Safeguards

To prevent similar silent regressions from reaching production:
1. **PyTorch → ONNX Parity Gate**: Release CI now computes maximum absolute difference between PyTorch and exported ONNX logits, gating promotion on `delta <= 1.2e-5`.
2. **Gold Standard Test Suite**: A locked benchmark of 3,965 challenging real-world crops with high repeating digit frequency must pass with zero delta before container tagging.
3. **Canary Verification**: Releases deploy behind a hash router with automatic fallback to serverless Lambda if error rate exceeds 0.01% or p95 exceeds 340ms.
